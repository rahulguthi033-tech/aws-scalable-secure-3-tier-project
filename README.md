# AWS Scalable & Secure 3-Tier Infrastructure

## Project Overview

This project demonstrates how to build a scalable,
secure and highly available 3-tier architecture on AWS.

## Architecture

1. Presentation Tier - Frontend Web Servers
2. Application Tier - Backend Application Server
3. Database Tier - Amazon RDS MySQL

## AWS Services

- Amazon VPC
- Amazon EC2
- Application Load Balancer
- Amazon RDS MySQL
- Internet Gateway
- NAT Gateway
- Security Groups
- IAM

## Technologies

- AWS
- Linux
- Python
- Flask
- Git and GitHub
